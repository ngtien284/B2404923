🎸 Bài tập nhóm – Website bán nhạc cụ
 📌 Giới thiệu dự án
Website bán nhạc cụ là dự án được thực hiện trong quá trình học tập nhằm xây dựng một hệ thống bán hàng trực tuyến, giúp khách hàng dễ dàng tìm kiếm, xem thông tin và lựa chọn các sản phẩm nhạc cụ phù hợp với nhu cầu.

🎯 Mục tiêu
- Xây dựng giao diện website bán nhạc cụ thân thiện, dễ sử dụng.
- Hỗ trợ khách hàng tìm kiếm và xem thông tin sản phẩm.
- Hỗ trợ quản lý giỏ hàng và đặt hàng trực tuyến.
- Hỗ trợ quản trị viên quản lý sản phẩm, danh mục và đơn hàng.
- Vận dụng kiến thức phân tích, thiết kế và phát triển hệ thống web vào thực tế.
